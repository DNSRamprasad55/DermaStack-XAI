# Evaluation Figures (`artifacts/figures/`)

Stores publication-ready charts and visual explanations generated by the evaluation and XAI pipelines:
1. `confusion_matrix_*.png`: Confusion matrix heatmaps for each model.
2. `roc_curves_*.png`: One-vs-rest multiclass ROC curves.
3. `class_distribution.png`: Bar chart of dataset distribution across the 7 HAM10000 classes.
4. `sample_gradcam_comparison.png`: Side-by-side comparison of Grad-CAM heatmaps.
