# DermaStack-XAI Requirements Specification

## 1. Scope & Objective

**DermaStack-XAI** delivers an end-to-end explainable deep learning pipeline for automated dermoscopic lesion classification. The software is engineered according to rigorous machine learning standards: strict separation of data splits, avoidance of data leakage via group partitioning, out-of-fold stacking meta-classification, gradient-based visual localization (Grad-CAM), and comprehensive performance accounting across all 7 HAM10000 diagnostic classes.

---

## 2. Functional Requirements

### FR-01: Dataset Ingestion & Validation
- **FR-01.1**: The system must ingest the HAM10000 dataset consisting of image archives and the master `HAM10000_metadata.csv`.
- **FR-01.2**: The pipeline must verify file existence, valid image dimensions, image format (RGB JPEG), and match every record to an image on disk.
- **FR-01.3**: The system must report any missing, corrupted, or duplicate image files.

### FR-02: Patient & Lesion Identifier Auditing (Leakage Prevention)
- **FR-02.1**: The system must inspect the `lesion_id` column. Because multiple images in HAM10000 originate from the same physical lesion, splitting must be performed using **Stratified Group Splitting** (`StratifiedGroupKFold`) grouped on `lesion_id`.
- **FR-02.2**: The pipeline must verify that the intersection of `lesion_id` sets across `train`, `validation`, and `test` splits is strictly empty ($\text{Train} \cap \text{Val} = \emptyset$, $\text{Train} \cap \text{Test} = \emptyset$, $\text{Val} \cap \text{Test} = \emptyset$).
- **FR-02.3**: Stratification must ensure proportional representation of minority classes (`df`, `vasc`, `akiec`) across all partitions.

### FR-03: Model Implementations
- **FR-03.1 Custom Lightweight CNN**:
  - Implemented from scratch using TensorFlow/Keras.
  - Multi-block convolutional design with batch normalization, pooling, and dropout.
  - Target parameter budget: $< 2$ million parameters.
- **FR-03.2 EfficientNetB0 Transfer Learning**:
  - Pre-trained on ImageNet.
  - Includes custom classification head for 7 classes.
  - Supports staged fine-tuning.
- **FR-03.3 ResNet50 Transfer Learning**:
  - Pre-trained on ImageNet with deep residual representation.
  - Custom classification head with global average pooling, dense layers, and dropout.
- **FR-03.4 Stacking Ensemble Meta-Learner**:
  - Meta-learner: Multinomial Logistic Regression with L2 regularization.
  - **Mandatory constraint**: Must be trained ONLY on out-of-fold (OOF) cross-validation predictions generated by base models during training, NEVER on in-sample predictions.

### FR-04: Visual Explainability (Grad-CAM)
- **FR-04.1**: Compute Class Activation Maps using gradient information from the final convolutional layer of each base model.
- **FR-04.2**: Generate an overlay blending the original dermoscopic image with the normalized heatmap using a standard colormap (`jet`).
- **FR-04.3**: Provide side-by-side visual comparison across the three base models to demonstrate consensus or divergence in visual attention.

### FR-05: Model Evaluation & Reporting
- **FR-05.1**: Evaluate all base models and the stacking ensemble on the isolated holdout test set.
- **FR-05.2**: Report overall accuracy, balanced accuracy, precision (macro & weighted), recall (macro & weighted), F1-score (macro & weighted), and one-vs-rest ROC-AUC.
- **FR-05.3**: Generate both unnormalized and row-normalized (recall) confusion matrices.
- **FR-05.4**: Clearly present per-class metrics to expose class imbalance effects.

### FR-06: Interactive Streamlit Web Application
- **FR-06.1**: Allow users to upload dermoscopic images (`.jpg`, `.jpeg`, `.png`).
- **FR-06.2**: Provide model selection options: Individual Base Models or Stacking Ensemble.
- **FR-06.3**: Display top prediction, probability distribution bar chart across all 7 classes, and clinical lesion details.
- **FR-06.4**: Render Grad-CAM heatmaps for the selected or all models.
- **FR-06.5**: Prominently display a mandatory Medical Disclaimer.

## 3. Non-Functional Requirements

- **NFR-01 Reproducibility**: Fixed random seeds (default `42`) across Python, NumPy, and TensorFlow. Fully serialized train/val/test split indices saved to disk.
- **NFR-02 Environment Compatibility**: Must run natively on Windows 11 with Python 3.12 64-bit and CPU computation mode.
- **NFR-03 Code Modularity**: Separation of concerns across configuration, data, models, training, evaluation, XAI, and application. Monolithic single-file architectures are forbidden.
- **NFR-04 Verification & Testing**: Automated test suite checking data leakage, model forward pass shapes, configuration validity, and metric calculation correctness.
- **NFR-05 Scientific Integrity**: No fabrication of training results or synthetic metrics. If a model has not been trained, its status must explicitly reflect this.
