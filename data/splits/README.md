# Data Splits Directory (`data/splits/`)

This directory stores reproducible partition manifests generated by `src/data/splitter.py`.

## Contents:
- `train_val_test_splits.json`: Mapping of image IDs and lesion IDs to their respective partitions:
  - `train_images`
  - `val_images`
  - `test_images`
- `cv_folds.json`: 5-fold cross-validation partition masks for generating out-of-fold predictions.

All splits are generated with fixed seeds and strictly enforce zero overlap of `lesion_id` across partitions.
