# Streamlit Application (`app/`)

This directory contains the user interface for DermaStack-XAI.

## Launching the App

To run the Streamlit application:

```bash
streamlit run app/app.py
```

## Clinical & Safety Features:
- Prominently displays the mandatory medical research prototype disclaimer.
- Clearly states that heatmap visualizations and class probabilities do not prove a diagnosis.
- Supports side-by-side comparison of individual base models and the stacking ensemble.
